# damai-id-generator-framework

`damai-id-generator-framework` 是 `damai-pro` 内部的分布式 ID 生成模块，用于为订单、支付、节目、用户等业务域提供趋势递增、可分片路由的全局唯一 ID。

## 项目定位

该模块基于百度分布式 ID 思路做 Spring Boot 工程化适配，作为 `damai-pro` 的基础框架能力被业务服务引入。它不直接承载业务逻辑，而是为高并发写入、分库分表和异步消息链路提供稳定 ID。

## 核心能力

- **全局唯一**：避免多服务、多实例并发写入时出现主键冲突。
- **趋势递增**：降低数据库索引维护成本，适合订单等高写入表。
- **Spring Boot 适配**：业务服务引入模块后即可复用统一 ID 能力。
- **Redis workId**：在原有数据库方式基础上增加 Redis 生成 `workId` 的能力。
- **分片友好**：可配合基因法、ShardingSphere 和业务字段完成数据路由。

## 使用边界

- ID 生成器只负责生成 ID，不负责业务幂等、库存一致性或订单状态流转。
- 如果业务需要按用户、订单或节目维度路由，应在业务层明确分片键策略。
- Redis 方式依赖服务的 Spring Redis 配置可用。

## 在 damai-pro 中的作用

高并发下单链路中，节目、座位、订单、支付等数据会跨多个服务和分片流转。统一 ID 能降低服务间耦合，并让消息、缓存、数据库记录具有可追踪的共同标识。
