# damai-id-generator-framework

`damai-pro` 内部的分布式 ID 生成模块，为订单、支付、节目、用户等业务域提供趋势递增、可分片路由的全局唯一 ID。

## 核心能力

- **全局唯一** — 多服务多实例并发写入无主键冲突
- **趋势递增** — 降低数据库索引维护成本，适合高写入表
- **Redis workId** — 支持 Redis 生成 `workId`，无需数据库配置表
- **分片友好** — 配合基因法、ShardingSphere 完成数据路由
- **Spring Boot 自动配置** — 业务服务引入即用

## 使用边界

- 仅负责 ID 生成，不涉及业务幂等或一致性
- 分片键策略由业务层决定
- Redis 方式依赖 Spring Redis 配置可用

## 在下单链路中的作用

高并发场景下节目、座位、订单、支付跨多服务和分片流转，统一 ID 降低耦合并提供可追踪标识。
