# 简历 · 项目经历

---

**小麦 AI 智能票务服务平台** &emsp;&emsp; AI 应用开发 &emsp;&emsp; 2025.07 - 2025.11

- **项目简介：** 基于 Spring Boot 3 + Spring AI 构建传统票务系统之上的多智能体平台，面向购票引导、规则问答、运维诊断与通用对话四类场景，提供意图路由、业务工具调用、RAG 知识问答、MCP 运维问数与 SSE 流式交互等全链路 AI 能力。

- **技术栈：** Java 17、Spring Boot 3、Spring AI、Function Call、RAG、Qdrant、Elasticsearch、MCP、SSE、JSQLParser、RabbitMQ、Prometheus

- **职责与技术实现：**

  1. **多 Agent 路由与 Run 编排：** 以"关键词加权评分 + 结构化意图识别"双通道路由，结合权限校验与置信度阈值，实现一句话分流到购票、规则、运维、通用四条技能链，配合 Run 状态机与 SSE 事件持久化，支持会话内路由切换、过程可回放。

  2. **Function Calling + 人审下单：** 基于 Spring AI Tool Calling 封装节目搜索、票档查询、下单准备等业务工具，下单等高风险动作走"预览 → approve/reject → 真实创建"模式，让用户用自然语言完成咨询到下单全链路，同时杜绝模型越权出票。

  3. **RAG 混合检索 + 自评估纠偏：** 叠加查询重写、向量+关键词混合召回、RRF 融合与 Rerank 重排，并对证据做置信度评估与改写补检索，证据不足则拒绝给确定答案以避免幻觉。

  4. **MCP Server 拆分 + 受控 NL2SQL：** 将日志与监控拆为独立 MCP Server，NL2SQL 走"Schema 召回 → 生成 → AST 校验 → 只读执行 → 自修复"流水线并强制白名单与敏感字段拦截，让运维以自然语言完成日志、链路、指标、数据查询等操作。

  5. **会话管理与调用可观测：** 基于 Advisor 链实现窗口记忆、标题生成与 Token/延迟/费用追踪，配合 RabbitMQ 异步压缩会话摘要、刷新用户画像，支撑多轮上下文记忆与模型调用监控。

- **项目成果：**

  1. 购票咨询、规则问答等高频场景 AI 自动解决率达 72%，人工客服介入量下降约 40%。
  2. 知识问答检索命中率（Recall@5）达 85%，结合置信度拒答机制将幻觉率控制在 5% 以下。
  3. 运维排障平均定位时间（MTTR）缩短约 40%，日志/指标/链路查询从多步手动操作简化为自然语言一句话完成。
