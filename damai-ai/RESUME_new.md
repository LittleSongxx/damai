# 简历项目内容（两个后端项目）

## 项目一：大麦 — 分布式票务交易与 AI 智能助手平台

**大麦 — 分布式票务交易与 AI 智能助手平台**                                  **核心开发者**                                  **2025.10 - 至今**

- **项目简介：** 基于 **Spring Cloud Alibaba + Spring AI** 构建的分布式票务交易平台，覆盖节目检索、选座购票、支付退款、分库分表与服务治理等场景；并以业务系统为事实源扩展 AI 智能助手，支持自然语言购票、规则问答与微服务运维诊断。
- **技术栈：** Java 17、Spring Cloud Alibaba、Nacos、Gateway、OpenFeign、Sentinel、Seata、ShardingSphere、MyBatis-Plus、MySQL、Redis/Redisson、RabbitMQ、Elasticsearch、Prometheus、Spring AI、Qdrant、MCP、SSE、Vue 3
- **职责与技术实现：**
  1. **微服务架构：** 按业务拆分网关、用户、节目、订单、支付等服务，基于 **Nacos、OpenFeign** 与网关完成服务治理与统一鉴权。
  2. **高并发选座下单：** 基于 **Redis 与 Lua 原子脚本** 完成余量与座位校验、相邻座位匹配及锁座，结合 **Redisson 分布式锁** 与幂等避免抢座冲突和重复下单。
  3. **跨服务一致与支付：** 以 **RabbitMQ 异步建单** 解耦服务，结合 **Seata 分布式事务** 与延迟消息实现超时关单、失败回滚与防重复支付。
  4. **分库分表与扩容：** 基于 **ShardingSphere 基因法** 对订单等核心表按业务维度复合分片，并实现可预演、增量的 **平滑数据迁移** 方案。
  5. **AI 业务助手：** 基于 **Spring AI Tool Calling** 封装节目查询与购票预览，AI 仅生成 **待人工确认动作**、不绕过业务鉴权与库存约束。
  6. **RAG 知识问答与智能运维：** 基于 **RAG** 将 **Qdrant 向量检索与 Elasticsearch 全文检索** 结果经 **RRF 融合与 Rerank 重排** 构建高准确率混合问答，支持 **SSE 流式输出**，并接入 Prometheus 指标与日志实现微服务自然语言运维诊断。

## 项目二：惠巷 — 本地生活服务平台

**惠巷 — 本地生活服务平台**                                  **核心开发者**                                  **2025.05 - 2025.10**

- **项目简介：** 基于 **Spring Boot 3** 构建的本地生活点评与优惠券秒杀平台，覆盖商铺查询、达人探店、关注互动、优惠券秒杀与订阅提醒等场景，聚焦 **单机高并发下的削峰、缓存、限流与数据一致性闭环**。
- **技术栈：** Spring Boot 3、MyBatis-Plus、MySQL、Redis/Redisson、Kafka、Lua、Caffeine、Prometheus、Vue 3
- **职责与技术实现：**
  1. **秒杀一致性闭环：** 设计 **Lua 原子扣减、可靠投递与消费幂等** 的秒杀链路，以 **快照回滚与对账日志** 保障宕机、超时、异常下的数据最终一致。
  2. **异步削峰：** 拆分下单为 **Redis 预扣减与 Kafka 异步建单**，通过可靠投递与消费幂等降低数据库写入峰值、提升抢券吞吐。
  3. **多层缓存治理：** 构建本地缓存、布隆过滤器与 Redis 的 **多级缓存**，结合空值缓存与互斥重建，系统化解决缓存穿透、击穿与雪崩。
  4. **限流防刷：** 实现 **令牌桶与滑动窗口** 双模式限流并前置资格令牌，结合白名单、封禁与阈值惩罚拦截恶意刷单与重复提交。
  5. **运营与可观测：** 基于 **分片延迟队列** 支撑开抢预通知、超时关单与到券提醒，构建买家排行榜并通过 **Prometheus** 观测核心链路指标。
