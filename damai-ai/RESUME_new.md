## 大麦AI — 智能票务服务平台

**AI 应用开发** | 2025.10 - 2026.05

### 项目简介

为售票平台搭建的统一 AI 助手，用户通过对话完成规则咨询、票档查询与订单创建，下单前生成预览供人工确认；管理员可用自然语言查询业务数据与微服务运行指标。系统通过 Route-Skill-Execute 编排引擎统一承接购票、知识检索、通用问答、运维分析四类请求，自动完成意图路由与执行模式选择。

**技术栈**：Spring Boot 3.5、Spring AI 1.0、Qdrant、Elasticsearch、Redis/Redisson、RabbitMQ、Resilience4j、OpenTelemetry、Prometheus、Vue 3

### 职责与技术实现

**1. 统一助手编排与多模式执行**

设计分层降级技能选择策略，结合置信度门控自动决策直接执行、发起澄清或进入 ReAct 循环。自研 Skills 系统支持 DB 热更新与 Tool 沙箱隔离，对话后经 RabbitMQ 异步触发记忆压缩与用户画像提取，主链路零阻塞。

**2. 知识库建设与 CRAG 检索**

文档按版本管理并标注时效与受众元数据，基于内容哈希增量更新，过期自动下线。检索阶段以 Dense、HyDE、Sparse 三通道多路召回，经 RRF 融合与 Rerank 精排后叠加时效过滤。LLM 对结果进行三元评估——正确则直接生成，模糊则拆解子问题补充检索，错误则改写查询重试，持续低置信度拒答。离线评测 Recall@5 超 0.88、NDCG@5 超 0.85、Faithfulness 超 0.93。

**3. 购票业务闭环与人在环审批**

构建 LLM 自主调用业务工具的购票链路，覆盖节目推荐、票档查询、购票预览全流程。下单等高危操作进入多状态审批，下单前自动重验库存与身份信息，被拒绝时生成替代推荐方案。连续多轮无法解答或命中负面情绪关键词时自动建议转人工客服。

**4. 纵深安全防护与护栏体系**

构建输入护栏、输出护栏、工具调用护栏递进防线，集成 PII 脱敏、毒性拦截与幻觉事实校验。输入护栏覆盖 18 种 Prompt 注入攻击模式，输出护栏由 LLM 逐条验证生成内容是否被证据支撑。NL2SQL 引入 JSqlParser AST 多层校验，拦截非 SELECT 语句、危险函数与敏感字段，合成合法率超 99%。

**5. MCP 运维工具集与系统韧性**

自研 Log 与 Metrics 两个 MCP Server，以标准 MCP 协议暴露日志多维检索、traceId 链路串联、JVM 健康巡检等 15 个工具。实现 NL2SQL 管道覆盖 Schema 检索、LLM 生成 SQL、AST 安全校验、只读执行与失败自动修正重试。引入独立熔断与溢出保护机制，基于 Redis 实现阶段快照与断点恢复，分布式追踪与指标采集覆盖全链路。
